# Tabletop Audio

Локальна Android-first PWA звукова панель для настільних ігор. Ігри та імпортовані аудіокопії зберігаються в IndexedDB цього браузера; сервіс-воркер кешує оболонку застосунку для офлайн-запуску.

## Запуск локально

Будь-який статичний HTTP-сервер може віддавати корінь цього каталогу. Наприклад, якщо Python доступний:

```sh
python -m http.server 8000
```

Відкрийте `http://localhost:8000`. Для встановлення на телефон сайт має бути доступний через HTTPS (або з localhost для локальних перевірок).

## Застереження прототипу

- Android-браузери відрізняються підтримкою відтворення у фоні, під час блокування екрана та реакції на аудіофокус. Це треба перевірити на телефоні до розширення застосунку.
- Повторення файлу використовує `HTMLAudioElement.loop`; чутний проміжок залежить від самого файлу та декодера браузера.
- Перехід у прихований стан призупиняє атмосферу як безпечну поведінку при перериванні. Деякі браузери приховують PWA при блокуванні екрана, тому цільове відтворення при заблокованому екрані ще не гарантовано.
- Підтримувані формати та межі сховища залежать від браузера і пристрою. При нестачі квоти імпорт показує помилку.
- Дані прив'язані до профілю браузера; очищення даних сайту видалить ігор та їхні імпортовані копії.
- Щоб розширити підтримку кодеків, можна додавати формати після перевірки сумісності Android-пристроїв.
